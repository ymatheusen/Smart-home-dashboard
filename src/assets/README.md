# Sfeerbeeld

`living-room.webp` is een speciaal gegenereerde interieurfoto voor de hero en decoratieve tegelachtergronden. Het origineel is geoptimaliseerd naar WebP (ongeveer 206 KiB). De foto wordt lokaal meegeleverd in de PWA, zelfstandige HTML en Android-app en wordt door de serviceworker vooraf opgeslagen. Er zijn geen externe beeldverzoeken tijdens gebruik.
